# 个人项目选题：图书借阅系统

沿用第 02 周在 README 中确定的选题，本文件记录项目规划及每周实现范围。

| 项目 | 内容 |
| --- | --- |
| 项目名称 | 图书借阅系统（工程名 `library-monolith`） |
| 目标用户 | 小型图书馆的读者、图书管理员；系统管理员负责账号与权限 |
| 优先实现的业务场景 | 图书借出与归还：管理员为读者选择一本可借的馆藏副本办理借出，生成借阅记录和应还日期；归还时结束借阅记录，并把副本恢复为可借 |
| 核心模型一 | `Book`（书目）：书名、作者、ISBN、分类，以及该书目下馆藏副本的可借数量 |
| 核心模型二 | `BorrowRecord`（借阅记录）：读者、借出的副本、借出日期、应还日期、归还日期、借阅状态 |

## 本周实现范围（第 03 周）

- 在仓库根目录 `monolith/` 下创建 Spring Boot 4.0.x + Maven 工程，包名 `com.zjgsu.wch`。
- 只完成应用启动、`application.yml` 基础配置、一个验证运行状态的 `GET /api/hello` 接口、Actuator 健康检查和 `contextLoads` 启动测试。
- 不实现 `Book`、`BorrowRecord` 等业务模型，也不包含 Service、Repository、数据库和完整 REST API，这些留到后续几周。


## 本周实现范围（第 04 周）

本周完成“查询书目与副本 → 办理借出 → 查询借阅记录 → 归还”的单体流程。

- `Book` 表示书目：书名、作者、唯一 ISBN。
- `BookCopy` 表示实际馆藏副本，关联一个 Book，并记录是否已借出；Book 与 BookCopy 为一对多。
- `BorrowRecord` 表示一次借阅，关联一个副本，记录读者姓名、借出日期、应还日期和归还日期；副本与借阅记录为一对多。
- 创建书目时自动创建一个副本，本周不提供额外副本管理接口。
- Service 检查“已借出副本不能再次借出”和“已归还记录不能重复归还”；借期为 30 天。
- 借出/归还使用事务，同时保存副本状态与借阅记录。Controller 只接收 DTO、调用 Service 并返回响应。
- MySQL 保存三张业务表，测试使用 H2。读者本周以姓名字段记录，不实现独立读者账户、预约、罚款、登录权限或并发抢借保障。

验证记录见 [第四周作业](homework/week-04/index.md)，表结构见 [数据库设计](database.md)。
