# 第二周：项目选题与功能规划

## 项目选题

- 项目名称：图书借阅系统。
- 复用仓库：https://github.com/Joe-Wang-hangzhou/microservices-practice-2403080546
- 确定过程：从本次作业提供的候选方向中选择图书借阅系统，将图书、读者、借阅、预约、罚款作为主要业务模块

### 选题说明

本项目面向小型图书馆的日常借阅场景，解决人工管理中图书可借状态不清、借还记录难以追踪、预约顺序不明确及逾期罚款统计不便等问题。主要目标用户包括需要查询、借阅和预约图书的读者，负责馆藏维护与借还登记的图书管理员，以及负责账号和权限配置的系统管理员。选择该题目是因为业务流程清晰，图书、读者、借阅、预约和罚款之间有明确联系，既能够先实现单体系统，也能支撑后续数据库持久化、认证、服务拆分、消息、事务、监控和部署等课程任务。初期限定为单个小型图书馆，暂不实现跨馆调拨、电子书阅读和在线支付。

## 功能规划

| 模块           | 具体功能                                                     |
| -------------- | ------------------------------------------------------------ |
| 图书管理       | 维护书名、作者、ISBN、分类等书目信息；维护馆藏副本及可借、已借出、待取书等状态；按书名、作者、分类查询；查看可借数量 |
| 读者管理       | 管理读者资料和账号状态；查看个人借阅、预约和罚款记录；停用账号时限制新增借阅与预约 |
| 借阅管理       | 管理员选择读者和可借副本办理借出；记录借出日期和应还日期；归还时更新借阅记录和副本状态；查询当前及历史借阅记录 |
| 预约管理       | 没有可借副本时按书目预约；按预约时间排队；读者可取消预约；副本归还后分配给队首读者并记录取书期限；逾期未取则释放副本并继续处理下一位预约 |
| 罚款管理       | 归还时依据逾期天数生成罚款；查看未缴和已缴记录；管理员确认线下缴纳后更新状态，防止同一次归还重复生成罚款 |
| 账号与权限管理 | 区分读者、图书管理员和系统管理员的操作权限；后续加入登录认证和工作人员账号管理 |



### 本周完成内容

1. 确定图书借阅系统选题
2. 明确读者、图书管理员、系统管理员三类用户及其需求。
3. 规划图书管理、读者管理、借阅管理、预约管理、罚款管理、账号与权限管理六个模块。
4. 区分书目与馆藏副本，明确预约针对书目、借阅针对副本。
5. 描述查询、借出、归还、逾期罚款及预约分配的核心业务流程。
6. 明确项目边界和后续课程的演进方向。

### 后续计划

先实现单体应用中的图书、读者和借还业务，再完善预约及罚款管理并加入数据库持久化, 逐步完成登录认证、服务拆分、消息、事务、监控和部署。
